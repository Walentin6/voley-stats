# 01 — Visión del producto

## Qué es

VoleyStats es una herramienta de **scouting de vóley**: registra lo que hace cada jugador
durante un partido y lo convierte en estadísticas útiles para el cuerpo técnico.
Se inspira en Data Volley 4, el estándar profesional, pero apunta a ser **más simple de
aprender** y **accesible** para clubes, selecciones juveniles y entrenadores sin
presupuesto para software profesional.

## Para quién

| Usuario | Necesidad |
|---|---|
| Estadístico con experiencia | Cargar muy rápido con teclado y códigos |
| Entrenador / ayudante | Cargar con botones en una tablet sin aprender códigos |
| Cuerpo técnico | Ver estadísticas en vivo (tiempos muertos, entre sets) y después del partido |

## Principios

1. **En vivo primero.** Cada pantalla se diseña pensando en un partido real: pocas
   pulsaciones, botones grandes, nada que bloquee.
2. **Nunca perder datos.** Guardado inmediato, deshacer siempre disponible, respaldo exportable.
3. **Sin conexión.** Debe funcionar en un gimnasio sin wifi.
4. **Compatible con el estándar.** Los códigos siguen la lógica de Data Volley para que
   los estadísticos que ya lo conocen se adapten enseguida.
5. **Crecer por etapas.** Cada versión debe ser usable por sí misma.

## Qué NO es (por ahora)

- No es un reemplazo completo de Data Volley (video, informes avanzados, base de datos de
  temporadas). Eso llega en etapas posteriores — ver [09 — Hoja de ruta](09-hoja-de-ruta.md).
- No tiene cuentas de usuario ni sincronización en la nube.
- No sigue rotaciones ni posiciones en cancha todavía.
